Helix Noise · demos

One field, every renderer

Every page below drives its visuals from the same HelixNoise.create(...) — a grid-free, divergence-free helical flow field with four dials: slope (size of things), helicity (handedness), coherence (noise → structure) and churn (time). Plain HTML, no build; serve the repo root (npm run demo) and click around.

Receipts

Why this is not curl noise with a control

Curl noise finite-differences a noise potential: div-free up to the stencil's truncation, on the grid it was differenced on. This is a closed-form curl, so ∇·u = 0 is an identity measurable at any point at any scale. The page runs both, side by side.

canvas

The parity wall JS · WASM · GLSL

One field, three backends, same slice, same instant — compared value-for-value rather than by eye. JS↔WASM lands at ~1e-16 (both float64), the GPU at ~1e-6 because fp32 is fp32. A page printing "0" there would be lying.

webgl2

Seamless by construction tileable

Snap every wavevector to the integer lattice and the sum is exactly 2π-periodic — as arithmetic, not as a blend. The readout prints the seam mismatch live: ~1e-15 tileable against ~2 free.
