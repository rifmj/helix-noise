An exact Navier–Stokes solution — exactNS

Every other page here shows a field that looks like a fluid. This one is one: create(exactNS({k0, nu})) puts every wave on a single |k| = k₀ with one handedness, which makes the flow Beltrami (∇×u = ±k₀u). The nonlinear term then reduces to a pure gradient that the pressure absorbs, and what is left is exact viscous decay — every amplitude shrinking as e^(−νk₀²t), which is precisely what decay does. Scope, stated plainly. This is the classical decaying Beltrami (Trkalian) class: free space, no boundaries, and a nonlinearity that is inert rather than balanced. It is an exact solution, not a turbulent one — no cascade, no intermittency, and the whole field decays at one rate. Note also that the curl in row A is read from field.sampleGrad(), not from vorticity(): on a circular field the sampler computes w = s·κ·u by assignment, so testing ∇×u = k₀u against it would be circular reasoning. The gradient is an independent analytic code path, so the residual below is a real measurement. And the "wider band" button does exactly what it now says: it raises kmax to k₀+2 while leaving kmin at k₀, so the shell becomes one continuous band rather than two separate shells — and because the wavenumbers are redrawn it is a new mode table on the same seed, not the original field stretched.
