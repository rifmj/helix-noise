Polarization — ellipticity × polarizationAxis

Nine fields that share a seed, a spectrum and a helicity slider. Only the polarization differs. Down the rows, ellipticity takes each wave from a circular corkscrew (1, tubes) to a flat linear oscillation (0, sheets). Across the columns, polarizationBias combs those waves along a world axis — the grain, drawn vertically here. Neither is anisotropy, which only moves where the waves point; these change how each wave polarizes. Streaklines are integrated with field.sample(); colour is the genuine helicity density u·ω.

Note what the grain costs: a wave can only be so polarized, so polarizationBias and the chirality ε·s are jointly capped at √(d²+χ²) ≤ 0.97. In the top row (ellipticity 1) there is almost no room left — the grain barely bites. Lower the ellipticity and it opens up. That is the covariance staying positive, not a knob quirk.
