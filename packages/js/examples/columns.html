Vortex columns — strainedColumn, counterSwirlColumns, axisymmetric

A tornado, and — unlike everything else in this library — an exact stationary solution of the Navier–Stokes equations: an inward strain holds the filament open against viscosity, and the balance is exact. Its vorticity is purely axial and exactly Gaussian, ω_z = (εa/ν)·e^(−a r²/2ν), so raising the strain makes the filament thinner and brighter at the same time — the peak εa/ν climbs as the width √(2ν/a) falls. That coupling is what a real intensifying vortex looks like, and here it is not art-directed.

Counter-rotating pair sets two of them side by side, spinning opposite ways. Between the cores the swirl doubles into a jet; across the mid-plane it cancels identically, so that plane is impermeable — nothing crosses it, ever. The readout measures both halves live: u·n and |ω| read machine zero on the plane while staying large off it, which is what separates a real invariant from a vacuous one. (Stacking the pair along a shared axis instead is degenerate — a column's vorticity never decays along its own axis, so the two would cancel everywhere.) Funnel drops the physics and uses the bare axisymmetric chassis: any two profiles you like, still exactly incompressible, and still smooth on the axis — the r² factorisation removes the division by r, so there is no seam down the middle. Drag to orbit.
